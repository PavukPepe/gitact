# Практическая работа №12 — Создание первого пайплайна

Цель работы

- Реализовать GitLab CI пайплайн для курсового проекта, включающий сборку, линтинг, две дополнительные функциональные задачи, корректную переадресацию URL ревью-приложения и выгрузку артефактов.

Содержание

1. Цель работы
2. Описание пайплайна
3. Конфигурация `.gitlab-ci.yml`
4. Скриншоты результатов выполнения задач
5. Вывод


Описание пайплайна

- Стадии: install, build, lint, test, e2e, deploy
- Задачи:
  - Проверка сборки проекта (stage: build)
  - Проверка синтаксических ошибок линтером (stage: lint)
  - Доп. функциональные задачи: unit smoke tests (stage: test), простой e2e-опрошик (stage: e2e)
  - Деплой preview (stage: deploy) — Review Apps с корректным URL
- Артефакты: `eslint-report.json`, `.next/` (сборка), `public_preview/`

Как проверялось

- Запуск в GitLab с настроенным раннером, у которого есть теги `docker`.
- Для проверки URL нужно настроить mapping в GitLab Environments / Review Apps, чтобы `https://$CI_ENVIRONMENT_SLUG.example.com` вело на ваш сервер.

Результаты

- Поместите скриншоты выполнения каждой задачи здесь и добавьте комментарии.

Вывод

- Оценка выполненных пунктов и рекомендации.
